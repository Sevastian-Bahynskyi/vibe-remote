How to use Vibe Remote Sessions, switching, and handoffs
  1. Add a workspace and a Claude account under Settings.
  2. Start a session: pick the account, the workspace, and a new or earlier conversation.
  3. On your phone, switch Claude to the same email, then tap Open live session.

Run several sessions at once

Start one session per task. Each gets its own name in the Claude app, so New session never disturbs the ones already running.

Pick up an earlier conversation

Choose it under Conversation when starting a session, or use Move / edit on a running one and save to restart it there.

Continue in another agent

Open a checkpoint’s Actions under Settings, choose a Codex or Claude destination, open it in the same workspace, and type exactly continue.
